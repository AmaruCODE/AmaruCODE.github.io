# Sílabo: Principios Fundamentales de Diseño Experimental con Python

## Descripción del Curso
Este curso introduce los principios fundamentales del diseño experimental mediante un enfoque práctico utilizando Python. Los estudiantes aprenderán a aplicar los conceptos de aleatorización, replicación, control local y ortogonalidad en el diseño y análisis de experimentos, implementando estos principios con herramientas computacionales modernas.

## Objetivos de Aprendizaje
- Comprender los principios teóricos que sustentan el diseño experimental
- Desarrollar habilidades para implementar estos principios usando Python
- Aprender a diseñar experimentos válidos y eficientes
- Adquirir capacidad para simular y evaluar diferentes diseños experimentales
- Desarrollar criterio para seleccionar diseños apropiados según el contexto de investigación

## Requisitos Previos
- Conocimientos básicos de estadística
- Familiaridad elemental con programación (preferentemente Python)
- Laptop con Python instalado (se recomienda Anaconda)

## Estructura del Curso

### Clase 1: Introducción al Diseño Experimental y Python FECHA: 01 MARZO
- Fundamentos del método científico y la experimentación
- El rol de los principios fundamentales en el diseño experimental
- Configuración del entorno Python para diseño experimental
- Bibliotecas esenciales: NumPy, Pandas, SciPy, statsmodels
- **Práctica**: Preparación del entorno y primeros pasos con Python para experimentación

### Clase 2: Principio de Aleatorización FECHA: 08 MARZO
- Fundamentos teóricos de la aleatorización
- Importancia de la aleatorización para la validez interna
- Implementación de técnicas de aleatorización en Python
- Generación de secuencias aleatorias y asignación de tratamientos
- **Práctica**: Creación de un script para aleatorizar unidades experimentales

### Clase 3: Replicación y Tamaño de Muestra FECHA: 15 MARZO
- El principio de replicación: fundamentos y propósito
- Cálculo de tamaño de muestra y potencia estadística
- Implementación con Python: bibliotecas statsmodels y scipy.stats
- Simulaciones para determinar el número óptimo de réplicas
- **Práctica**: Análisis de potencia para diferentes diseños experimentales

### Clase 4: Control Local y Bloqueo FECHA: 22 MARZO
- Fundamentos del control local y su importancia
- Estrategias de bloqueo para reducir la variabilidad
- Identificación de variables de bloqueo
- Implementación de diseños en bloques con Python
- **Práctica**: Simulación y análisis de un experimento con y sin bloqueo

### Clase 5: Ortogonalidad y Balance FECHA: 29 MARZO
- Concepto de ortogonalidad en diseños experimentales
- Diseños balanceados vs. no balanceados
- Matrices de diseño y sus propiedades
- Implementación y verificación de ortogonalidad en Python
- **Práctica**: Construcción y evaluación de diseños ortogonales

### Clase 6: Confusión y Efectos de Interacción FECHA: 05 ABRIL
- Principios para evitar la confusión entre factores
- Identificación y manejo de interacciones
- Visualización de interacciones con Python
- Implementación de diseños que evitan confusión
- **Práctica**: Análisis de datos con interacciones y diagnóstico de confusión

### Clase 7: Simulación de Experimentos FECHA: 12 ABRIL
- Principios de simulación para evaluar diseños
- Generación de datos experimentales sintéticos
- Evaluación de robustez y eficiencia de diferentes diseños
- Técnicas de Monte Carlo para diseño experimental
- **Práctica**: Simulación comparativa de diferentes diseños experimentales

### Clase 8: Optimización de Diseños FECHA: 19 ABRIL
- Criterios de optimalidad (D-óptimo, A-óptimo, etc.)
- Algoritmos de optimización para diseños experimentales
- Implementación en Python con bibliotecas especializadas
- Evaluación y comparación de diseños optimizados
- **Práctica**: Optimización de un diseño experimental para un caso específico

### Clase 9: Principios para Diseños Avanzados FECHA: 26 ABRIL
- Aplicación de principios fundamentales en diseños complejos
- Diseños factoriales fraccionados
- Diseños de superficie de respuesta
- Implementación y análisis con Python
- **Práctica**: Desarrollo de un diseño experimental avanzado

### Clase 10: Integración de Principios y Proyecto Final FECHA: 03 MAYO
- Revisión integrada de todos los principios fundamentales
- Marco para la selección de diseños apropiados
- Consideraciones éticas en el diseño experimental
- Presentación de proyectos finales
- **Práctica**: Presentación y evaluación crítica de proyectos de diseño experimental
